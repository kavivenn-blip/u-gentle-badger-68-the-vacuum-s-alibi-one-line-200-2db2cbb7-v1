A program that writes one line in which a robot vacuum explains why it missed a spot: "I left it there as evidence, Exhibit A. If anyone asks, I was charging at the time. The charger will confirm it." The vacuum treats the spot as evidence in a case, gives itself a charging alibi, and calls the charger as its witness.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline, 112 characters, one line). Deterministic, offline, standard library only.
