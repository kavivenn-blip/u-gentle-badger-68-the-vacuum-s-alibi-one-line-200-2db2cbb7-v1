A program that writes one line in which a robot vacuum explains why it missed a spot: "The spot bribed me with a lost earring. We do not speak of this. The earring and I have an understanding." The spot bribed the vacuum with a lost earring, and the two of them have an understanding about it.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline, 105 characters, one line). Deterministic, offline, standard library only.
